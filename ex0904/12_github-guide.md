# GitHub 가이드

## 설치 방법
1. Git 설치: `git-scm.com` 접속 → 설치 파일 다운로드 → 설치
2. GitHub 가입: `github.com` 접속 → 계정 생성
3. GitHub Desktop 설치: `desktop.github.com` 접속 → 설치 파일 다운로드 → 설치

## GitHub Desktop으로 연동 후 Push까지
1. GitHub Desktop 실행 → GitHub 계정 로그인
2. `File` → `Clone repository` (또는 `Add local repository` 로 기존 폴더 연결)
3. 파일 수정 후 좌측에서 변경사항 확인
4. 하단 커밋 메시지 입력 → `Commit to main`
5. 상단 `Push origin` 클릭하여 GitHub에 업로드
